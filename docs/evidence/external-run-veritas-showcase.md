## Result

The same real external execution produced three different outcomes under controlled evidence changes:

`VERIFIED` → complete, internally consistent evidence

`REJECTED` → evidence contradicts the claim or integrity bindings fail

`ABSTAIN-NEEDS-EVIDENCE` → required proof is missing

The decision is evidence-driven rather than model-confidence-driven.

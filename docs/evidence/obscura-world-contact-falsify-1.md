# Obscura FALSIFY-1 — Consistent Fiction vs Coordinator-Owned World Contact

Date: 2026-08-20 / 2026-08-21 UTC
Branch: `lab/obscura-veritas-browser-run`

## Result

The experiment deliberately separated three questions:

1. Is the executor evidence internally consistent and integrity-bound?
2. Is the evidence fresh and bound to the coordinator's current challenge?
3. Did the claimed browser action actually contact an independently observed external endpoint?

Observed matrix:

| Case | Generic verifier | Live challenge verifier | Coordinator world-contact verifier |
|---|---|---|---|
| Honest Obscura | VERIFIED | VERIFIED | VERIFIED |
| Live fake MCP worker, no HTTP request | VERIFIED | VERIFIED | ABSTAIN-NEEDS-EVIDENCE |

The live fake MCP worker received the genuine current challenge and fabricated browser-shaped navigation, snapshot, evaluate, and network results without making the HTTP request. Generic and live-challenge verification both accepted the fabricated execution at 100%. The coordinator-owned echo server recorded no request for the liar's nonce, so the world-contact verifier refused certification.

The honest Obscura run produced an in-window GET from the Ubuntu node, and the browser observation contained the random response token generated by the Windows coordinator only after receiving that request.

## Proven architectural lesson

Freshness, artifact integrity, structured semantic consistency, and challenge binding are all necessary but are not sufficient to prove an external-world effect.

A required world-effect claim needs at least one observation written by a trust domain outside the executor's authority.

This does **not** yet prove causal-path identity. A malicious executor may be able to contact the independent witness by a different mechanism (for example raw HTTP rather than the claimed browser capability) and then launder the legitimate witness token into fabricated browser evidence.

## Next falsification target

**Witness laundering / causal-path binding**:

- issue a genuine fresh browser challenge;
- let a malicious live MCP worker avoid launching Obscura;
- have the worker make a raw HTTP request to the coordinator witness itself;
- obtain the legitimate coordinator-generated response token;
- embed that token into fabricated browser evidence;
- test whether the current world-contact verifier falsely certifies the claimed browser action.

If this succeeds, the next required primitive is not merely `writer_domain`; it is evidence that binds the independent witness event to the intended capability/process/path.

No production WE/Agentic OS components are modified by this lab experiment.
